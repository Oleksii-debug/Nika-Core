Профіль ресурсів

Профіль обмежує навантаження нових звичайних завдань. Якщо ресурсів недостатньо, завдання очікує. Вибір зберігається після перезапуску.

Перевірка збереженого профілю.

Автозапуск Windows

Змініть позначку й натисніть «Зберегти автозапуск». Налаштування діє лише для вашого облікового запису. Воно відкриває програму після входу у Windows, але не надає дозволу повторювати незавершені дії.

Перевірка автозапуску.

Джерела команди

Виберіть папку та два різні файли для порівняння командою. Підтримуються TXT, MD, HTML, CSV, JSON, PDF, DOCX та XLSX, до 16 МіБ кожен. Нові налаштування застосовуються до нових завдань; розпочаті зберігають свої джерела.

Перевірка збережених налаштувань.

Команда

Поточний пакет запускає команди через безпечний детермінований режим без LLM.

Запланований запуск

Заплануйте один запуск команди з поля «Що має зробити Nika?». Перевірка ресурсів повторюється до допуску або крайнього часу запуску. Виконана дія не повторюється. Скасування розкладу не зупиняє вже запущене завдання; для цього є «Зупинити агента».

Запланованих запусків ще немає.

Показано не більше 50 записів на сторінці. Для інших запусків перейдіть до наступної сторінки.

# Packaged resource observer dependency

The actual Windows resource-admission composition uses the existing
PsutilResourceObserver. It therefore requires psutil in the GUI/packaging profile,
including when no agent/LLM extra is installed. The resource package retains its
lazy observer export; the resource schema initializer uses only the standard
library. Base-only persistence does not acquire an eager optional import.

The GUI extra now reuses the existing psutil>=7,<8 requirement. Reviewed uv0.13.6
regenerated the lock and pip exports: the same210 resolved distributions and all
their versions remain; core, build and both M12 requirement exports are unchanged.
The packaging profile adds only the already locked psutil7.2.2. Source-bound
manifest hashes are regenerated by the existing compiler, not manually certified.

Primary provenance: https://pypi.org/project/psutil/7.2.2/ and the official
https://psutil.readthedocs.io/stable/ API reference. The selected distribution
declares BSD-3-Clause. The actual locked local installation contains its full
1548-byte LICENSE, SHA256
b89c063b3786e28e0c0a38f1931db61fed35e69dd2a2966fbecffee0f46c8d10.
The existing bounded notice collector materializes its copyright, conditions and
disclaimer from that installed file; no metadata-only license stub is substituted.

The independent notice-omission/regeneration oracle now includes psutil. Required
runtime notice coverage includes this observer explicitly. Final Windows M11/M12
must still prove the actual frozen module/distribution owner, native extension,
notice text and extracted distributable. Local license observation is not packaged
Windows proof, source provenance attestation, human testing or NVDA verification.

On earlier source00de, M11 failed importing packaged startup because the packaging
profile omitted psutil. M12 then timed out starting the frozen proof process; no
timeout was enlarged. New exact-head gates are required after the profile repair.
Section7 remains NOT DONE until applicable source, integration and release gates.
